# Renesas-smart-server-cooling-system
Smart Server Cooling System using Renesas BGK-RA6E2, BLE, Temperature/Humidity Sensor, and PWM-based Fan Control.
A temperature-based smart cooling system developed using the **Renesas RA6E2** microcontroller. The system monitors temperature and humidity using the **HS4001 sensor** and automatically controls a cooling fan using **PWM**.

The project also uses **Bluetooth Low Energy (BLE)** for communication and monitoring through the Renesas Quick Connect ecosystem.

## Project Overview

Server racks generate significant heat during operation. Excessive temperature can affect the reliability and lifetime of electronic equipment.

This project provides an automated cooling solution that:

* Monitors temperature and humidity
* Automatically controls a cooling fan based on temperature
* Controls fan speed using PWM
* Provides LED-based temperature indication
* Uses BLE for wireless communication
* Can be integrated with the Renesas Quick Connect Sandbox application

## Working Principle

The HS4001 sensor continuously measures the temperature and humidity.

The measured temperature is compared with a predefined threshold.

```text
        ┌─────────────────────┐
        │    HS4001 Sensor    │
        │ Temperature/Humidity│
        └──────────┬──────────┘
                   │
                   ▼
        ┌─────────────────────┐
        │    Renesas RA6E2    │
        │     Controller      │
        └──────────┬──────────┘
                   │
             Temperature
                   │
                   ▼
        ┌─────────────────────┐
        │ Temperature Based   │
        │   Control Logic     │
        └───────┬─────┬───────┘
                │     │
                ▼     ▼
           PWM Fan    LED
            P104     P105
                │
                ▼
          Cooling System

        ┌─────────────────────┐
        │   DA14531 BLE       │
        │ Wireless Monitoring  │
        └─────────────────────┘
```

## Fan Control

The cooling fan is controlled using a PWM signal generated by the RA6E2 timer.

Different PWM duty cycles can be used to control the fan speed.

| Temperature Condition    | Fan Operation |
| ------------------------ | ------------- |
| Below threshold          | Fan OFF       |
| Low temperature range    | Low speed     |
| Medium temperature range | Medium speed  |
| High temperature         | Full speed    |

The PWM duty cycle can be adjusted in the firmware according to the required cooling level.

## LED Indication

The LED connected to **P105** provides a visual indication based on the temperature condition.

The firmware can turn the LED ON/OFF according to the configured temperature threshold.

## Bluetooth Communication

The **DA14531 BLE module** is used for wireless communication.

The system can be extended to transmit:

* Temperature
* Humidity
* Fan status
* Fan control information
* LED status

The project is designed to work with the **Renesas Quick Connect ecosystem** and Quick Connect Sandbox application.
